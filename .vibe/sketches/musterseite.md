# Skizze: Musterseite `zuordnungen/proportional-erkennen`
1. Titel, Ziel in einem Satz („Du erkennst, ob eine Zuordnung proportional ist.“), Anschluss an die Seite davor.
2. Abschnitt `einstieg`: Dreifachansicht mit Regler k (Handy: Minutenpreis). Frage: „Was bleibt gleich, wenn du k bewegst?“
3. Abschnitt `erklaerung`: Pfeiltabelle (SVG), Satz „Doppelt so viele Minuten, doppelt so viel Geld“, Merke gegen „je mehr, desto mehr“.
4. Abschnitt `beispiel`: Beispielkasten mit zwei Tabellen, eine proportional, eine nicht, Quotient *y* : *x* je Zeile.
5. Abschnitt `uebung`: (a) true-false, (b) single-choice, (c) number, (d) generated mit Mistakes; danach „Das kannst du jetzt“.
